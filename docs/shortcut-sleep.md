# Сон с iPhone → бот (iOS «Команды»)

Каждое утро команда читает «Анализ сна» из «Здоровья» и отправляет его боту.
URL и твой личный токен бот присылает по команде `/shortcut`.

## 1. Сама команда

«Команды» → вкладка **Команды** → **+** → назови «Сон → бот».

1. **Найти образцы Здоровья** (Find Health Samples)
   - Тип: **Анализ сна**
   - Фильтр: **Дата начала** · **за последние** · **18 часов**
   - Сортировка: Дата начала, по возрастанию; ограничение выключено
2. **Повторить с каждым** (Repeat with Each) — вход: *Образцы Здоровья*
   - Внутри добавь **Текст** и собери строку из трёх полей через `;`:
     `Дата начала;Дата окончания;Значение`
     - Вставь переменную *Повторяемый объект* → тапни по ней → **Дата начала**.
       Тапни ещё раз → **Формат даты: ISO 8601**, **Включать время: вкл**.
     - `;`
     - То же для **Дата окончания** (тоже ISO 8601 со временем).
     - `;`
     - *Повторяемый объект* → **Значение**.
3. После «Повторить» — **Объединить текст** (Combine Text):
   вход *Результаты повтора*, разделитель **Новая строка**.
4. **Получить содержимое URL** (Get Contents of URL)
   - URL: из `/shortcut` (`…/functions/v1/sleep-webhook`)
   - Метод: **POST**
   - Заголовки: `X-Token` = токен из `/shortcut`
   - Тело запроса: **JSON**, поле `text` (Текст) = *Объединённый текст*
5. (Для проверки) **Показать результат** — вход *Содержимое URL*.

Запусти команду вручную один раз: iOS спросит доступ к «Здоровью» — разреши
«Анализ сна». Ответ должен быть вида `{"ok":true,"night":"…","asleep":"7 ч 10 м"}`.
После проверки шаг 5 можно удалить.

## 2. Автоматизации (две, сервер не дублирует данные)

«Команды» → **Автоматизация** → **+**:

- **Время суток** 07:05, ежедневно → **Запускать сразу** → действие *Запустить команду «Сон → бот»*.
- **Приложение** → Telegram → **Открыто** → **Запускать сразу** → то же действие.
  Страховка: пока iPhone заблокирован, «Здоровье» недоступно, и утренний запуск
  может не получить данные. Тогда сон уйдёт при первом открытии Telegram,
  и бот разберёт ночь отдельным сообщением.

Выключи «Уведомлять при запуске», чтобы не мешало.

## Если что-то не так

- `{"ok":false,"error":"no sleep samples","parsed":0}` — даты не в ISO 8601
  или в «Здоровье» нет сна за 18 часов (часы не синхронизировались).
- `unauthorized` — неверный токен в заголовке `X-Token`.
- Если сна с часов мало (нет стадий) — позже можно перейти на Health Auto Export.
