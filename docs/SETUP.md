# Setup

Requirements: a Supabase account, a Telegram account, Node 20+, `gh` (for the Mini App), optionally a Gemini API key.
Everything runs from the repo root; `SUPABASE_PROJECT_REF` is the `<ref>` in `https://<ref>.supabase.co`.

## 1. Supabase
```bash
export SUPABASE_PROJECT_REF=<ref>
npx supabase login
npx supabase link --project-ref $SUPABASE_PROJECT_REF
npx supabase db push                     # applies supabase/migrations/*
```
Then, once, in the Supabase SQL editor (the scheduler reads the project URL from Vault):
```sql
select vault.create_secret('https://<ref>.supabase.co', 'project_url');
```
(`cron_secret` is generated by the first migration.) Make sure the `pg_cron`, `pg_net` and `vault`
extensions are enabled (Dashboard → Database → Extensions).

## 2. Secrets
```bash
npx supabase secrets set BOT_USERNAME=<bot> MINIAPP_URL=https://<user>.github.io/<pages-repo>/
scripts/set-secret.sh GEMINI_API_KEY      # value is typed hidden
```

## 3. Deploy functions + Telegram webhook
```bash
scripts/deploy.sh
scripts/setup-telegram.sh                 # copy the BotFather token first; sets token, webhook secret and webhook
```

## 4. Mini App
Create an empty **public** repo `<user>/<pages-repo>`, enable GitHub Pages (branch `main`), then:
```bash
MINIAPP_REPO=<user>/<pages-repo> VITE_API_URL=https://<ref>.supabase.co/functions/v1/api scripts/deploy-miniapp.sh
```

## 5. First run
Send `/start` to your bot. **The first user becomes the owner**; everyone else needs an invite link
(generated in the bot). Do this before sharing the bot username.

## Optional
- `scripts/setup-github.sh`: GitHub token for the contribution graph.
- `scripts/import-money-manager.ts`, `scripts/backfill-fx.ts`: Money Manager import and FX history.
- `.github/workflows/health.yml`: set repo variable `SUPABASE_PROJECT_REF` and secret `HEALTH_TOKEN`
  (the owner's `ingest_token`) to get a GitHub-email alert if the bot goes down.
- iPhone Shortcuts (back-tap expense entry, daily sleep and steps from Health): [docs/IPHONE.md](docs/IPHONE.md).

## Costs / limits
Supabase free tier is enough for a few users. Gemini free tier may use your prompts for training;
the consent text says so, keep it accurate.

## Start over / transfer ownership
The owner cannot `/delete` themselves (the bot and invites hang on that account). To reset a deployment,
run in the Supabase SQL editor: `delete from public.users;` (everything cascades), then send `/start` again.

## Defaults you may want to change
- Base currency is USD, per-user in the app (Settings). Internally amounts are also stored in CNY for analytics.
- New users get timezone `Asia/Shanghai` and no supplements: set both in the app (Settings).

## Access tokens
Clients other than Telegram (iPhone Shortcuts, scripts, a desktop app) authenticate with a personal token in the
`X-Token` header. Tokens are stored only as SHA-256, each has a label and a scope, and can be revoked:

- `/tokens` lists them (never the values), `/newtoken <label> [app|study|ingest|*]` creates one (the message with the
  value deletes itself after a minute), `/revoke <label>` revokes it.
- Scopes: `app` (the Mini App API), `study` (study sync), `ingest` (iPhone Shortcuts, health check), `*` (everything).
- The token created for you at sign-up keeps working as label `legacy` with every scope. Prefer a separate token per client.
- `?token=` in the URL still works but is deprecated (the response carries a `Deprecation` header); use the header.
- 20 failed attempts from one address within 10 minutes are answered with 429.
