# Шаги, вес и пульс покоя с iPhone (iOS «Команды»)

Каждое утро команда читает «Здоровье» за вчера и отправляет боту: шаги, пульс
покоя и последний вес. Адрес и личный токен бот присылает по команде `/shortcut`.
Токен тот же, что у команды «Сон».

Дату команда не считает: она шлёт `dayShift: -1`, а вчерашний день сервер
определяет по часовому поясу владельца — так надёжнее, чем по времени телефона.

## 1. Сама команда (если собирать вручную)

«Команды» → **+** → назови **Тело бот**.

1. **Найти образцы Здоровья** (Find Health Samples) — шаги, см. фильтры ниже.
2. **Найти образцы Здоровья** — пульс в покое.
3. **Найти образцы Здоровья** — вес.
4. **Получить содержимое URL** (Get Contents of URL)
   - URL: `…/functions/v1/body-webhook` из `/shortcut`
   - Метод: **POST**
   - Заголовки: `X-Token` = токен из `/shortcut`
   - Тело запроса: **JSON**, четыре поля (все Текст):
     `dayShift` = `-1`,
     `steps` = результат шага 1,
     `restingHr` = результат шага 2,
     `weightKg` = результат шага 3
5. **Получить значение из словаря**: ключ `reply`, из *Содержимое URL*
6. **Показать уведомление**: *Значение словаря*

Пустые поля бот пропускает: день без веса или без пульса запишется по шагам.

## 2. Фильтры «Здоровья»

В готовом файле они пустые — iOS падает при импорте, если задать их заранее.
Открой команду и заполни три действия **Find Health Samples** сверху вниз
(iPhone на английском, поэтому названия кнопок английские).

- **Первое** — шаги. Sample Type: **Steps**. Calculate: **Sum**.
  Filter → **Start Date** · **is in** · **yesterday**.
  Второй фильтр обязателен: **Source** · **is** · твои часы (**Apple Watch**).
- **Второе** — пульс покоя. Sample Type: **Resting Heart Rate**. Calculate: **Average**.
  Filter → **Start Date** · **is in the last** · **7 days**
  (часы считают его не каждый день), Sort by **Start Date**, Limit **1**.
- **Третье** — вес. Sample Type: **Weight**, Sort by **Start Date**, Order **Latest First**,
  Limit **1**. Если в «Здоровье» веса нет, действие можно удалить — поле уйдёт пустым.

Порядок действий менять нельзя: первое уходит в `steps`, второе в `restingHr`,
третье в `weightKg`.

### Почему шаги надо ограничить одним источником

iPhone и часы пишут свои шаги отдельно. Приложение «Здоровье» показывает их
без задвоения, а **Find Health Samples** отдаёт сырые образцы от обоих устройств —
сумма выходит почти вдвое больше (23 286 вместо 12 000 за 22 сентября).
Фильтр **Source** оставляет один источник. Часы точнее телефона, но в день,
когда часы сняты, шаги будут занижены — это честнее, чем двойной счёт.

Шаги считаются ровно за один день (**yesterday**); неделя стоит только у пульса
покоя, потому что часы пишут его не каждый день.

Запусти команду один раз вручную: iOS спросит доступ к «Здоровью» — разреши.
В уведомлении должно быть «Записал за …: 8 432 шага, …», и число шагов обязано
совпасть с приложением «Здоровье» за тот же день.

## 3. Автоматизация

«Команды» → вкладка **Автоматизация** → **+** → **Время суток** 08:30, ежедневно →
**Запускать сразу** → действие *Запустить команду «Тело бот»*.

Время позже утреннего сообщения не случайно: часы синхронизируют вчерашний день
не сразу. Повторная отправка того же дня ничего не ломает — день перезаписывается.

## Вес без часов

Вес можно написать боту словами: `вес 71.4`. Записывается сегодняшним днём,
шаги и пульс покоя при этом не затираются.
